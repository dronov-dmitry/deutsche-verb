Полностью офлайн приложение для изучения немецких глаголов. Без сервера, без регистрации, без интернета.

Возможности:
• ~3000 глаголов уровней A1–C1
• Карточки с анимацией переворота и отслеживанием прогресса
• Фильтр по типу: слабые, сильные, смешанные
• Фильтр по уровню: A1, A2, B1, B2, C1
• Поиск по инфинитиву или переводу
• Тёмная тема
• Переключение языка: русский / украинский
• Отслеживание прогресса — отмечайте выученные глаголы
• Статистика по уровням
• Описания глаголов с примерами употребления
